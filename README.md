# The Goober's Guide

This repository separates the new application from the previous local prototype.

- [`implementation/frontend`](implementation/frontend/README.md): frontend for the new implementation.
- [`implementation/backend`](implementation/backend/README.md): backend for the new implementation.
- [`docs`](docs/README.md): milestone plans and logs, grouped by status (in progress, completed, paused, archive, reference).
- [`legacy`](legacy/): archived prototype, product and MVP documents, tests, and development tooling.

The archived `legacy/docs/PRODUCT.md` describes the broader product direction. `legacy/docs/MVP_SCOPE.md` and the archived root `AGENTS.md` describe the former local prototype and its boundaries.
